# Primeiros passos

Roteiro para quem acabou de chegar ao projeto.

1. Leia a [visão geral](../index.md) e a [ideia central](../index.md#ideia-central).
2. Entenda as [camadas da arquitetura](../architecture/index.md) e o [pipeline de uma refeição](../architecture/pipeline-refeicao.md).
3. Conheça as [regras fixas](../architecture/decisoes.md) — elas só mudam com um ADR.
4. Suba o MVP seguindo [Ambiente local](instalacao.md).
5. Veja [onde fica cada coisa](estrutura-repositorio.md) e quem é responsável por cada pasta.
6. Antes do primeiro PR, leia [Como contribuir](../guides/contribuir.md).

!!! info "Dois repositórios"
    Este site documenta o projeto, mas **o código fica em outro repositório**, que também contém o diário técnico `docs/DESENVOLVIMENTO.md` (etapa atual, ADRs, métricas e questões em aberto). A visão computacional (fase 2) fica em um terceiro repositório.
