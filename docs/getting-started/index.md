# Primeiros passos

Roteiro para quem acabou de chegar ao projeto.

1. Leia a [visão geral](../index.md), a [ideia central](../index.md#ideia-central) e o [escopo](../produto/escopo.md).
2. Entenda as [camadas da arquitetura](../architecture/index.md) e o [pipeline de uma refeição](../architecture/pipeline-refeicao.md).
3. Conheça as [regras fixas](../architecture/decisoes.md) — elas só mudam com um ADR.
4. Suba o MVP seguindo [Ambiente local](instalacao.md).
5. Veja [onde fica cada coisa](estrutura-repositorio.md) e quem é responsável por cada pasta.
6. Antes do primeiro PR, leia [Como contribuir](../guides/contribuir.md).

!!! info "Repositórios"
    Este site documenta o projeto, mas **o código fica em outros repositórios**:

    - [`ia`](https://github.com/residencia-ia-Challenge-2/ia): aplicação, pipelines e avaliação. Contém também o diário técnico `docs/DESENVOLVIMENTO.md` (etapa atual, ADRs, métricas e questões em aberto).
    - [`data`](https://github.com/residencia-ia-Challenge-2/data) (`mira-dados`): fontes, ETL, curadoria, Data Quality e publicação do banco.
    - Visão computacional (fase 2): repositório próprio.

    Quem é dono de quê está em [Escopo](../produto/escopo.md#repositorios).
